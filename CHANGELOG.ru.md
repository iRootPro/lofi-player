# История изменений

Здесь фиксируются все заметные пользовательские изменения. Проект следует
[Semantic Versioning](https://semver.org/).

## [0.3.1] — 2026-11-13

### Изменено

- В title bar TUI теперь показывается текущая версия, если ширина терминала
  позволяет; Playback Doctor также явно показывает версию приложения.

## [0.3.0] — 2026-11-13

### Добавлено

- **Playback Doctor**: read-only модалка TUI (`D`) и команда
  `lofi-player doctor` с безопасной диагностикой mpv, зависимостей, конфига,
  DNS и API Radio Browser.
- Безопасные действия clipboard: sanitised support report и только hostname
  активного потока; report никогда не содержит path, query string или токены.

## [0.2.0] — 2026-11-13

### Добавлено

- **Discovery Radio Browser**: поиск по публичному каталогу станций прямо из
  TUI через `/`.
- Автоматический поиск через 350 мс после окончания ввода; поддерживаются
  обычный текст и фильтры `tag:`, `country:`, `lang:`.
- Видимая обратная связь о запуске в discovery: `Loading …` сразу после
  `enter`, затем `Playing … · not saved`, когда поток начал играть.
- Inline-подтверждения сохранения в discovery: успех, дубликат и ошибка
  сохранения.
- Постоянное действие `Radio Browser · not saved · s save` после закрытия
  discovery, поэтому активную несохранённую станцию всегда можно добавить в
  библиотеку.
- Кэшированные результаты как offline fallback, когда Radio Browser
  недоступен.

### Изменено

- Действие `enter` в discovery называется **play**. Оно запускает станцию, но
  не меняет `config.yaml`; `s` явно сохраняет её.
- Если несохранённая станция Radio Browser играет вне discovery, `s` сохраняет
  именно активную станцию. После сохранения `s` снова делится выбранной
  станцией из библиотеки.
- Metadata, stream-info и состояние кэша теперь надёжно обновляются после
  смены станций, даже когда оба потока сообщают одинаковые значения.
- Ошибки TUI теперь показываются короткими английскими сообщениями без
  внутренних деталей Go, mpv или HTTP.
